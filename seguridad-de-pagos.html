Políticas de seguridad para la transmisión de datos de tarjetas

Última actualización: 13 de agosto de 2026

En ANDERGO Language Academy tomamos medidas y precauciones razonables para proteger la información personal de nuestros usuarios. Aplicamos prácticas de seguridad destinadas a evitar que la información sea utilizada, modificada, divulgada o destruida de manera no autorizada.

Nuestro sitio web utiliza una conexión segura mediante tecnología SSL/TLS para cifrar la información transmitida entre el navegador del usuario y nuestros servicios.

Los pagos realizados en ANDERGO Language Academy son procesados mediante Azul, un proveedor externo especializado en el procesamiento seguro de pagos electrónicos.

ANDERGO Language Academy no almacena directamente números completos de tarjetas, códigos de seguridad CVV ni otros datos confidenciales de autenticación. Azul utiliza únicamente la información necesaria para procesar y autorizar cada transacción, de acuerdo con sus medidas y estándares de seguridad aplicables.

Las transacciones pueden estar protegidas mediante los servicios de autenticación 3D Secure, incluyendo Visa Secure y Mastercard Identity Check. Estos mecanismos permiten que la entidad emisora verifique la identidad del titular de la tarjeta cuando sea necesario.

Recomendamos consultar también las políticas de privacidad y seguridad de Azul para conocer cómo este proveedor procesa la información suministrada durante el pago.

Si el cliente identifica una transacción sospechosa o necesita asistencia relacionada con un pago, puede comunicarse con el Servicio al Cliente de ANDERGO Language Academy.
