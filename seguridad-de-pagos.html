Políticas de seguridad para la transmisión de datos de pago

Última actualización: 23 de agosto de 2026

En ANDERGO Language Academy tomamos medidas y precauciones razonables para proteger la información personal de nuestros usuarios. Aplicamos prácticas de seguridad destinadas a evitar que la información sea utilizada, modificada, divulgada o destruida de manera no autorizada.

Nuestro sitio web utiliza una conexión segura mediante tecnología SSL/TLS para cifrar la información transmitida entre el navegador del usuario y nuestros servicios.

Los pagos de Premium y los donativos se procesan mediante el proveedor que se identifica antes de confirmar la operación. El método disponible puede variar según el país, la moneda o el tipo de operación.

ANDERGO Language Academy no almacena directamente números completos de tarjetas, códigos de seguridad CVV ni otros datos confidenciales de autenticación. El proveedor de pago utiliza únicamente la información necesaria para autorizar y procesar la operación, de acuerdo con sus medidas y estándares aplicables.

Cuando se use tarjeta, la transacción puede estar protegida mediante 3D Secure, incluidos Visa Secure y Mastercard Identity Check. Estos mecanismos permiten que la entidad emisora verifique la identidad del titular cuando sea necesario.

Recomendamos revisar el aviso de privacidad y las condiciones del proveedor que aparezcan en el checkout o en el enlace de donativo. Si identificas una transacción sospechosa o necesitas asistencia, comunícate con el proveedor de pago y con ANDERGO Language Academy.
