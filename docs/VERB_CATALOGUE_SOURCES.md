# Verb catalogue sources

The English and Spanish verb catalogue extension is compiled into
`src/js/verbs/extended-verb-catalogues.js`.

- English verb forms: [Wordexample, “Most common verbs in English (1,000)”](https://www.wordexample.com/list/most-common-verbs-english/), accessed 2026-08-11.
- Spanish frequency lemmata and English glosses: [doozan/spanish_data](https://github.com/doozan/spanish_data), accessed 2026-08-11. The source data credits Wiktionary and FrequencyWords and is licensed CC-BY-SA; this derivative catalogue retains that attribution.

The first entries in each local catalogue remain the hand-reviewed ANDERGO records. The extension supplies frequency-ranked verb forms and an audio-first pronunciation fallback where a reviewed IPA transcription is not yet available.
